# Contributing

Keep `-Werror` clean and run the native tests (see README) before opening a
PR. The core stays freestanding: no libc, no malloc, no dependencies.

Things that are missing and would be accepted:

- T-spin detection and bonus scoring
- Combos and back-to-back
- Full 20-level gravity table
- Replay format spec + verifier
